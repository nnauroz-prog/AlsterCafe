# Maria · Tägliche 5-Minuten-Routine
*Ausdrucken und neben den iPad legen.*

---

## ☀️ Morgens (2 Min) · vor Öffnung

1. **iPhone öffnen** → Lesezeichen **„Alstercafé Admin"** → eingeloggt bleiben
2. **Setup-Status-Karte** angucken: 0 % Lücken? → alles ok. Lücken? → erst füllen.
3. **„Anfragen ansehen"** kurz prüfen — neue Reservierungen für heute?
4. **„Brötchen-Bestellungen"** prüfen — was muss heute abgeholt werden?

---

## 🍽 Mittagstisch eintragen (3 Min) · Mo–Fr morgens

1. **„Mittagsmenü bearbeiten"** öffnen
2. Heute's Tag finden, **Hauptgericht + Beilage** tippen
   *(z. B. „Linsensuppe mit Würstchen" + „dazu Brot")*
3. **„Wochenplan speichern"** ganz unten
4. Auf der Startseite checken: erscheint das Gericht oben?

**🎯 Sonntag-Trick:** Am Sonntag-Abend gleich die GANZE neue Woche eintragen.
Dann ist Mo–Fr morgens nur „Hauptgericht überprüfen".

---

## 📞 Anrufe & Anfragen (laufend)

| Was kommt rein | Was tun |
|---|---|
| **Reservierung-Mail** | → kurz zurückrufen oder antworten → im Admin „Erledigt" |
| **Brötchen-Bestellung-Mail** | → bestätigen + auf Wunschtermin notieren → im Admin „Erledigt" |
| **WhatsApp-Notification** (falls eingerichtet) | → in den Admin gehen für Details |

---

## 🛑 Wenn etwas nicht stimmt

- **Seite zeigt „Karte folgt in Kürze"** → Mittagstisch eintragen!
- **Mail-Spam-Filter frisst Reservierungen** → bei `info@alstercafe.de` Spam-Ordner checken
- **„Passwort vergessen"** → Verkäufer/Dev anrufen, nicht selbst raten
- **Site sieht komisch aus** → iPhone → „Verlauf löschen" → neu laden

---

## ⚙️ Was Sie NIE tun müssen

- Kein Code anfassen
- Keine Updates installieren
- Keine Backups erstellen (Supabase macht das automatisch)
- Keine Domain verlängern (Verkäufer/Dev)
