Mitgliederbereich

Tippen Sie unten auf den Bereich, den Sie pflegen möchten.

Kurze Anleitung — in 3 Schritten
  1. Bereich wählen. Tippen Sie unten auf die Kachel, die Sie ändern möchten (z. B. „Mittagsmenü bearbeiten").
  2. Ändern. Tragen Sie ein, was Sie möchten — Texte überschreiben, Felder ausfüllen, Bilder hochladen.
  3. Speichern. Klicken Sie unten auf den grünen Knopf „… speichern". Erst dann wird die Änderung übernommen — und erscheint von selbst auf der Webseite, auch auf den Handys Ihrer Gäste.

Über „← Zurück zur Übersicht" oben kommen Sie immer wieder hierher. Sie können nichts kaputt machen: In jedem Bereich gibt es unten „Auf Standard zurücksetzen".

Speisekarte

Hier pflegen Sie Ihre Frühstückskarte. Preise, Gerichte und Beschreibungen ändern Sie direkt — speichern Sie unten, dann erscheint alles sofort auf der Webseite. Mit „Als PDF herunterladen" erstellen Sie sich jederzeit eine frische Karte zum Ausdrucken.

Öffnungszeiten

Links steht der Tag (z. B. „Mo – Fr"), rechts die Zeit (z. B. „06:30 – 15:00"). Einfach überschreiben. Dann unten auf „Öffnungszeiten speichern" klicken.
